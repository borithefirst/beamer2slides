Compiling is fast: pull, converge and adopt compile a source many times,
and every pass now costs less. A tree compiled before is not compiled
again; passes stop when the aux files stop moving. Passes run on a
lualatex started early and waiting at the end of the preamble, up to
three per piece as memory allows. A lualatex pass is split into pieces
over up to four cores (frames skipped to labelled checkpoints, aux
merged, PDFs joined), a first compile's later passes too, and it
survives section inserts. An edit that stays inside frames typesets
only those frames. Fonts: a static font with a STAT table is written
from its own file, not from luaotfload's whole-font cache, and the
scripts' fallback chain is built where a glyph first needs it (-29% on
the Hebrew/Arabic deck). Adopt's base compile starts from the loop's
aux. The measurements are in docs/compile-latency.md.

slides.sty draws plain rectangles and table cells with pgf's system
layer instead of TikZ, pixel for pixel the same, and an adopted table
cell's colour no longer leaks into later frames.

Python 3.10 installs build again (numpy 2.2's types). pypdfium2 is held
below 5.14, whose PDFium reads ActualText and draws transfer functions
differently from the pure backend's port.
