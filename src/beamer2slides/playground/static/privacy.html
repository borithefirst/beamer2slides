beamer2slides playground

Privacy policy

← back to the playground GitHub ↗

This page is a converter, not a service with accounts. It takes a LaTeX beamer talk (typed, picked from the examples or uploaded as a compiled PDF), runs it through beamer2slides, and — only if you ask it to — creates the resulting deck in your own Google Drive.

What is asked of your Google account

Only when you press Create the Google Slides deck, and only then, Google asks you to sign in and grant one permission: https://www.googleapis.com/auth/drive.file. That permission reaches only the files this app itself creates — the deck it is about to build. Nothing else in your Drive can be listed, read or changed with it.

What happens to the access token

  • Your browser gets the token from Google and sends it with that one request.
  • The server holds it in memory for the single conversion and then drops it.
  • It is never written to disk, never logged, and never given to anyone else.
  • No refresh token is requested, so nothing here can act on your account later.

You can review or withdraw the permission at any time at myaccount.google.com/permissions. The deck itself is yours: it stays in your Drive until you delete it.

What the server keeps

  • The source or PDF you submit and everything the conversion produced (page images, backgrounds, the intermediate JSON), in a temporary folder named by a random job id.
  • Only the last 40 jobs are kept; older ones are deleted, and every job is gone when the container restarts, which happens whenever the playground has been idle for a while.
  • Ordinary web-server request lines (time, path, the address the request came from).

There are no accounts, no cookies, no analytics and no tracking. A job link (?job=…) is the only handle on a conversion; anyone who has the link can see that job for as long as it is kept, so treat it as you would a share link.

Who else is involved

  • Google — the sign-in script, and the Drive and Slides APIs that build the deck. Their handling of your data is governed by the Google privacy policy.
  • Google Fonts — the page loads the fonts the preview is drawn in.
  • The playground runs on Google Cloud Run. Nothing is sent to any other service.

Use of Google user data

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The data is used for the single purpose you asked for — creating your deck — and is not transferred to anyone, used for advertising, or read by a human.
