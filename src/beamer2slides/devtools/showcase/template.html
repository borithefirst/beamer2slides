beamer2slides · adopt

Google Slides → Beamer

We made six decks in Google Slides and ran each one through beamer2slides adopt, which writes a beamer source a person can edit. Every example shows the slide as Google renders it, the page the adopted main.tex compiles to, and the frame that draws it. The originals are open to anyone, view only, so you can compare them for yourself.

    How these were made

    The decks are written by devtools/showcase/decks.py. The lecture is built with the Slides API alone. The other five are .pptx files imported by Drive, which is how most shared decks are made. Every picture in them is drawn from a seed by devtools/showcase/art.py, and every word was written for this page.

    Left of the divider (or the left image, side by side) is Google's own getThumbnail of the slide. Right of it is the compiled adopted PDF, rendered at the same width. Neither was retouched. Match is the adopt benchmark's boxes score for that slide: of the ink inside the deck's element boxes, the share that lands in the same place in both renders. The examples include the slides where adopt falls short, and each caption says where.

    A frame's \slidestyle, \slideshapestyle and colour names are declared once in the preamble. The Preamble tab lists only the ones that frame uses. layout= selects a background template from the recovered theme, shown under Theme layout. Pictures and traced outlines are files in the tree (figures/, shapes/). Each deck's adopted source is the whole tree except fonts/. Its FONTS.txt lists the Google Fonts it expects there.
